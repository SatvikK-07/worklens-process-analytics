# Artifact policy

## Committed

- Python source, SQL schema, configuration, tests, and documentation
- Small deterministic samples under `data/sample/`
- Empty data-directory markers (`.gitkeep`)
- Machine-readable metric JSON/CSV, report figures, and generated Markdown
  reports when their generating script is committed
- Portfolio screenshots intentionally referenced by the README

## Generated and excluded

- Full synthetic CSVs under `data/synthetic/`
- Raw public logs under `data/real/raw/`
- Processed real-event-log datasets under `data/real/processed/`
- SQLite databases and WAL/SHM files
- Pickle/joblib model binaries
- Python, pytest, Ruff, notebook, coverage, build, and OS caches

These files are excluded because they are large, machine-specific, or unsafe to
review as source. Model pickle files must only be loaded when generated locally
from this repository.

No model binary is committed, including under `models/sample/`. Sample model
binaries are generated by `make train-sample` and removed by `make clean`.
Small sample CSVs under `data/sample/` are intentionally retained so reviewers
can inspect schemas and run fast checks without downloading a large dataset.
CSV files above 5 MB are forbidden outside `data/sample/`.

## Regeneration

```bash
make generate-data       # full synthetic product data
make db                  # local SQLite database
make train               # synthetic model artifacts and prediction CSV
make generate-sample-data
make train-sample
make external-data       # official public log + validation, when network permits
make reports
make check-hygiene
```

`make clean` removes all excluded runtime artifacts while preserving source,
small samples, metric JSON, reports, and screenshots.

`scripts/check_repo_hygiene.py` enforces this policy. It fails on caches,
compiled Python, local databases, model binaries, temporary files, archives,
and oversized non-sample CSVs. CI runs `make check-hygiene` before tests.
